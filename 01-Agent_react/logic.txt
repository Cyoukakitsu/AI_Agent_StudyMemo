二、ReAct 主循环 (src/loop.ts)
------------------------------

  一句话：最多 6 轮；每轮问 LLM，有合法 Action 就先执行工具、记入 history，
          否则看有没有 Final Answer，都没有就记一条 ERROR 再下一轮。

  步骤表:
    0. history = []
    1. 拼 prompt            buildPrompt   (prompt.ts)
    2. 调用 llm             llm(prompt)   (llm.ts)
    3. 解析 Thought/Action  parseAction   (prompt.ts)，只取第一轮
    4. Action 是合法工具?   是 -> 执行 tools[action].run(input) -> Observation
                                  写入 history，回到 1   (同条回复里的 Final Answer 被忽略)
    5. 否则有 Final Answer? 是 -> 返回答案，结束
    6. 都不是 (Action 非法/缺失)
                            -> Observation = "ERROR: invalid Action. Must be one of [...]"
                               写入 history，回到 1
    7. 6 轮仍无答案 -> 返回 "Failed: max steps exceeded."

  注意：判断顺序是「先工具、后 Final Answer」。
        这样模型一次回复里同时写了 Action 和 Final Answer 时，
        不会在没拿到 Observation 的情况下提前结束。

  流程图:

  [开始]
     |
     |  history = []
     v
  .-------------------.
  |   第 1~6 轮循环    |<-----------------------------------.
  '-------------------'                                     |
     |                                                       |
     | ① buildPrompt(question, history, tools)               |
     v                                                       |
  ② await llm(prompt)                                        |
     |                                                       |
     v                                                       |
  ③ parseAction(out) -> action, actionInput                  |
     |                                                       |
     v                                                       |
  ④ action 是 tools 里的合法工具?                             |
     |                                                       |
     +--- 是 ---> 执行工具 -> Observation                     |
     |            写入 history -------------------------------+
     |
     +--- 否 ---> ⑤ out 里有 "Final Answer:"?
                     |
                     +--- 是 ---> 返回答案，[结束]
                     |
                     +--- 否 ---> ⑥ Observation = ERROR: invalid Action
                                    写入 history ------------+
                                                             |
                                    (回到循环顶部) <----------'
     |
     v  (6 轮用完)
  返回 "Failed: max steps exceeded."


三、单轮 LLM 输出格式
---------------------

    Thought: 我需要先计算 ...
    Action: calculator
    Action Input: 21+21

    (工具执行后，buildPrompt 把这一轮按同样格式追加到 prompt 末尾)

    Thought: 我需要先计算 ...
    Action: calculator
    Action Input: 21+21
    Observation: 42

    (下一轮 LLM 可输出)

    Thought: 已有结果
    Final Answer: 42

  prompt 结构 (prompt.ts buildPrompt):
    固定说明 + 工具名列表 + 工具描述 + Question + 已完成的每一轮 history
  system prompt (llm.ts):
    要求严格按格式、每次回复只输出一轮。

  parseAction 规则:
    - 逐行扫描，只取第一个 Thought 块里的 Action / Action Input
    - 遇到第二个 "Thought:" 或 "Final Answer:" 就停止


四、模块依赖关系
----------------

    main.ts
      --> llm.ts     --> types.ts, openai(SDK, 指向 OpenRouter), .env 里的 OPENROUTER_API_KEY
      --> loop.ts    --> prompt.ts, types.ts
      --> tools.ts   --> types.ts

    prompt.ts --> types.ts

  各文件职责:
    types.ts   Tool / LLM / HistoryItem 类型
    tools.ts   calc (递归下降解析，不用 eval) + buildDefaultTools
    prompt.ts  buildPrompt 拼 prompt；parseAction 解析 LLM 输出
    llm.ts     createOpenrouterLlm：读 .env，调用 OpenRouter (OpenAI 兼容接口)，打印请求/响应
    loop.ts    reactLoop：核心循环
    main.ts    入口，组装以上部分并运行示例问题


五、示例执行轨迹（main.ts 默认问题）
------------------------------------

    Question: 请帮我计算 21+21，并统计答案字符串有多少个字符, 并且打印当前时间。

    Step 1:
      Thought: 先计算 21+21。
      Action: calculator / Input: 21+21
      Observation: 42

    Step 2:
      Thought: 再统计 "42" 的字符数。
      Action: word_count / Input: 42
      Observation: 字符数: 2, 词数: 1

    Step 3:
      Thought: 还需要当前时间。
      Action: get_current_time / Input: (空，默认 Asia/Shanghai)
      Observation: 2026-10-18 18:01:14 GMT+8

    Step 4:
      Final Answer: 计算结果为 42，"42" 的字符数为 2，当前时间为 2026-10-18 18:01:14 GMT+8。

    时序示意:

        用户        LLM        calculator    word_count    get_current_time
         |           |             |             |               |
         | 复合问题   |             |             |               |
         |---------->|             |             |               |
         |           | calculator  |             |               |
         |           |------------>|             |               |
         |           |<- Obs: 42 --|             |               |
         |           | word_count                |               |
         |           |-------------------------->|               |
         |           |<- Obs: 字符数:2 ----------|               |
         |           | get_current_time                          |
         |           |------------------------------------------>|
         |           |<- Obs: 2026-10-18 ... --------------------|
         |           | Final Answer: ...         |               |
         |<----------|             |             |               |
